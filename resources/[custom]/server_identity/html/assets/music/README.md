## Drake / ICEMAN
We **cannot** download or provide Drake (or any copyrighted) MP3s.

Legal options:
1. Buy / stream ICEMAN from an official store
2. Export or rip **your own** purchased files
3. Drop them into this folder and point `music.tracks` in `config.js` at those filenames
4. Or keep the Mixkit Bay playlist above

## Controls
- **Space** play / pause · **-** / **=** volume · prev/next when multiple tracks exist

Restart `ensure server_identity` after changing files so FiveM re-streams `html/**`.
